Voiceblock 出口成方

说出物品的名字，直接把它拿到手上。

基于 Vosk 的完全离线中文语音识别，面向中文玩家 —— 尤其是视障玩家（没法靠眼睛在背包里翻找物品）。

✨ 它解决什么问题

普通玩家找一个物品要在背包里翻半天；视障玩家基本不可能完成这件事。 VoiceBlock 让你按住一个鼠标侧键，说出物品名字，东西就到手上 —— 全程不用看屏幕，也不需要联网。

识别在本地完成（内置 Vosk 中文模型），断网、离线、单人存档、服务器都能用。

🎮 怎么用

  1. 把对应版本的 jar 放进 mods/
  2. 首次启动会把语音模型解压到 config/voiceblock/vosk-model/
  3. 进游戏，按住鼠标侧键 5 说出物品名（按下有"叮"的提示音），松开后自动识别
  4. HUD 会显示识别到的内容，聊天栏会告诉你成功还是失败（失败会说清楚原因）
按键 默认 作用
key.voiceblock.use 鼠标侧键 5 按住说话，松开取物
key.voiceblock.learn 鼠标侧键 4 学习模式：手持物品按住说话，记住你的发音

两个键都可以在「控制 → 按键绑定 → VoiceBlock」里改。

🗣️ 7 个取物来源

按住键说话后，模组会按优先级依次尝试下面的来源，找到就停：

顺序 来源 默认 说明
1 背包 ✅ 自己身上的 36 格 + 副手
2 精妙背包 ✅ 读取背包里面的物品，不是背包本身
3 末影箱 ⬜ 玩家私有空间，默认关闭（可按需打开）
4 潜行盒 ✅ 1.20.5+ 可用
5 AE2 ✅ 需要无线终端已绑定到 ME 网络
6 汤姆的简易储存 ✅ 无线终端，或周围 8 格内的存储终端
7 周围箱子 ✅ 半径 16 格内的容器（可在配置里调小）

用 /voiceblock source list 可以随时查看每个来源的开关、是否可用、优先级和半径。

🌐 联机 / 服务器

服务端也要装同一个 jar，否则只能取自己背包里的物品（模组会提示你）。

装了两端之后：客户端只负责识别，把「物品 ID + 数量」发给服务端，由服务端真正执行取物。 这样末影箱、AE2 网络、箱子里的东西才不会出现"读取到空壳"的问题。

🎓 学习模式（口音救星）

口音重、或者某个物品怎么念都识别不准？

  1. 手持那个物品
  2. 按住鼠标侧键 4，说出你平时怎么叫它
  3. 松手，这个发音就被记住了（写进 config/voiceblock/manual_overrides.json）

如果这个物品之前已经录过发音，会弹两个按钮让你选：覆盖旧发音，或者加为模糊名称（两个都保留）。

💬 命令

命令 作用
/voiceblock 帮助
/voiceblock debug 看最近一次识别的 5 个候选
/voiceblock bind <序号> [物品ID] 把某个候选绑定到物品
/voiceblock list 查看所有手动绑定
/voiceblock remove <拼音> 删除一条绑定
/voiceblock reload 热重载配置
/voiceblock source list 查看所有物品源状态
/voiceblock source enable|disable <名字> 开关某个来源
/voiceblock source priority <名字> <数字> 调整优先级（越小越先尝试）
/voiceblock source radius <名字> <数字> 调整扫描半径
/voiceblock test <物品ID> [数量] 诊断用：不说话，直接走一次取物链路

/voiceblock test 在联机排查时特别好用：一句话就能知道服务端装没装、通道通不通、哪个来源在报错。

🧩 兼容性说明

  • 物品词典覆盖原版 + Create / 机械动力等常见整合包物品（2200+ 条），启动时还会自动从注册表补充
  • 拼音模糊匹配：说"原石"、"yuanshi"、"安山机壳" 这类都能命中
  • 精妙背包 / AE2 / 汤姆的简易储存 / 潜行盒都是软依赖：没装就自动跳过，不会报错
  • 内置模型较小，识别一般够用；想要更高精度可以往 config/voiceblock/vosk-model/ 放一个更大的 Vosk 中文模型，会自动优先使用

❓ 常见问题

Q：说了没反应？ 先看聊天栏有没有提示。如果提示"未找到"，说明你选中的来源里没有这个物品； 用 /voiceblock source list 检查来源开关，或者用 /voiceblock test <物品ID> 直接验证链路。

Q：服务器上取不到箱子里的东西？ 服务端没装模组。联机必须两端都装。

Q：识别不准？ 用学习模式（侧键 4）录一遍你自己的发音，比改任何设置都有效。

Q：支持英文吗？ 目前只针对中文语音优化。
