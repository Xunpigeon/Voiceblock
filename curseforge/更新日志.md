# VoiceBlock 版本历史

## v2.0.9 — 2026-10-23

### 🔧 重要修复：专用服务器上容器取物全部失效

**现象**：单人和局域网一切正常；连专用服务器时，只有自己背包里的物品能取，
末影箱 / 潜行盒 / 精妙背包 / AE2 / 汤姆储存 / 周围箱子全部失败。

**根因**：公共代码里引用了客户端类 `net.minecraft.client.Minecraft`。
专用服务器加载这个类时被 Forge 的 `RuntimeDistCleaner` 判定为 dist 违规并抛错，
于是所有依赖它的容器源一起失效，只有不调用它的背包源还能用。

**修复**：把客户端查找拆成独立类，主类改用字符串反射进入，字节码中不再含任何客户端类型引用。
四个平台共用这段代码，同时修复。

### ✨ 新增

- **Fabric 服务端权威取物**：之前 Fabric 是纯客户端实现，服务端根本不加载模组，联机读不到容器；
  现在 `environment: "*"` + `main`/`client` 双入口，C2S/S2C 网络通道，由服务端执行取物。
  服务端没装时自动降级为本地取物并给出提示。
- **Fabric 学习模式**：此前只有 Forge / NeoForge 有。现在 Fabric 也支持鼠标侧键 4，
  以及 `/voiceblock _learn replace|alias`，已有发音时可选择「覆盖」或「加为模糊名称」。
- **`/voiceblock test <物品ID> [数量]`**（四个平台）：不经过麦克风，直接走一次完整取物链路，
  联机排查"服务端装没装 / 通道通不通 / 哪个源报错"时一句话自证。

### 🩹 其它修复

- Vosk 初始化移出静态初始化块并 `catch Throwable`：原生库缺失时不再让客户端崩在启动阶段
- 开发环境 `run/` 拆分为 `run-client/` 与 `run-server/`
- `fabric.mod.json` 版本号与构建版本对齐

## v2.0 系列（2.0.0 ~ 2.0.8）

> 这一段此前没有逐版记录，这里合并说明最终形态。

- **7 个取物来源**：背包、精妙背包、末影箱、潜行盒、AE2、汤姆的简易储存、周围箱子，
  按优先级自动尝试，任一来源可单独开关 / 调优先级 / 调半径
- **服务端权威取物**：Forge / NeoForge 客户端只发「物品 ID + 数量」，服务端执行并回包
- **学习模式**：手持物品按住侧键 4 说话，把发音写进 `manual_overrides.json`
- **物品词典扩充**：原版 + Create 等整合包物品 2200+ 条，启动时从注册表自动补全
- **多加载器统一**：Fabric 1.20.1 / Fabric 1.21 / Forge 1.20.1 / NeoForge 1.21 四份产物

## v1.3.0 — 2026-10-17

### 识别率提升：N-best 多候选重排序
- Vosk 返回前 5 个候选（不再只看第 1 名）
- 三层匹配：手动绑定 → 精确名称/别名 → N-best 拼音评分

### 手动绑定
- `config/voiceblock/manual_overrides.json`：把自己的口音硬绑到某个物品
- 可导出分享给其他玩家

### 物品自动发现
- 启动时从注册表扫描物品，补齐 JSON 词典里没有的模组物品
